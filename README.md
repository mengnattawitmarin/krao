# เกราะ KRAO

ผู้ช่วยตรวจและเตือนภัยไซเบอร์บนมือถือ Android ภาษาไทย — เน้นกัน **แอปดูดเงิน** ที่แฝงมาเป็นแอปหน่วยงานรัฐหรือธนาคาร

## ดาวน์โหลด
หน้า **Releases** → ไฟล์ `krao-build-N.apk` ล่าสุด → เปิดบนมือถือ Android 8.0 ขึ้นไป → อนุญาตติดตั้งจากแหล่งนี้

> รุ่นทดสอบ เซ็นด้วยคีย์ทดสอบ อัปเดตทับกันได้ ยังไม่ใช่รุ่นขึ้น Play Store

## v0.1 ทำอะไรได้
- **ตรวจสุขภาพเครื่อง** คะแนน 0–100: รหัสล็อกจอ, แพตช์ความปลอดภัย, USB debugging, root, การติดตั้งจากแหล่งอื่น, การเข้ารหัส
- **สแกนแอป** ทุกตัว ให้ระดับ ปกติ / น่าสงสัย / อันตราย พร้อมเหตุผลภาษาคน และปุ่มถอนสิทธิ์/ถอนแอป
- **เฝ้าระวังอัตโนมัติ** ทุก ~15 นาที เตือนเมื่อ: มีแอปใหม่จากนอกร้านค้า, แอปได้สิทธิ์ควบคุมหน้าจอ / ผู้ดูแลอุปกรณ์ / อ่านการแจ้งเตือน
- **ถูกแฮ็ก?** ขั้นตอนรับมือทีละข้อ + ปุ่มโทร 1441 + เบอร์ธนาคาร 14 แห่ง (ใช้ได้ออฟไลน์)

## สิ่งที่แอปทำไม่ได้
ไม่มีแอปไหนกันได้ 100% เกราะตรวจได้เท่าที่ Android เปิดให้ (ไม่ต้อง root) ไม่ลบแอปให้เองโดยไม่ถาม และตรวจมัลแวร์ที่ฝังในเฟิร์มแวร์เครื่องไม่ได้

## ความเป็นส่วนตัว
ทุกอย่างประมวลผลในเครื่อง ไม่มีบัญชีผู้ใช้ ไม่มีโฆษณา ไม่มีตัวติดตาม — ดู [PRIVACY.md](PRIVACY.md)
